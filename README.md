# ノート & タスク環境 (VS Code)

デイリーノートと TaskChute のタスク管理を VS Code の中で完結させる環境。

**このフォルダだけで完結しています。** 中のファイルは、すべてこのフォルダからの相対パスで
参照し合っています。フォルダごとコピーすれば、別の PC でもそのまま同じように動きます。

```
30_note/                      <- VS Code でここを開く
  .vscode/settings.json       設定 (パスはすべてこのフォルダからの相対)
  .taskchute/
    config.json               節・Project・Mode などの設定
    days/YYYY-MM-DD.json      タスクデータ (1日1ファイル)
  20_daily/YYYY/MM/DD.md      デイリーノート
  notes/YYYY-MM-DD-タスク名.md  タスクに紐づけたメモ
  80_tamplate/Daily.md        デイリーノートのテンプレート
  80_tamplate/task/*.md       タスクメモのテンプレート
  tools/vscode-taskchute/     拡張機能のソース
  install.ps1                 このPCに拡張機能を入れるスクリプト
  README.md                   このファイル
```

外に持つのは **VS Code の拡張機能フォルダに置くリンク 1 つだけ** です
(`%USERPROFILE%\.vscode\extensions\local.taskchute-vscode-0.1.0`)。
これは VS Code の仕様上どうしても必要な置き場所で、`install.ps1` が面倒を見ます。

## 別の PC へ移すとき

GitHub の public リポジトリで持ち運びます。

**https://github.com/tk0-ds/taskchute-vscode**

**記録 (タスクデータ・デイリーノート・メモ) は `.gitignore` で除外してあり、リポジトリには
一切上がりません。** 仕組みだけが同期され、記録は PC ごとに独立して持ちます。
public なので、会社PC 側で GitHub にログインする必要はありません。

移す先で、フォルダ名は `30_note` に揃えておくと迷いません。

```bash
git clone https://github.com/tk0-ds/taskchute-vscode.git 30_note
```

動くかどうかを先に確かめます (Node.js があるときだけ。無ければ飛ばして構いません)。

```bash
node tools/vscode-taskchute/test/run.js
```

「すべて成功」と出たら、拡張機能を入れます。

```bash
powershell -ExecutionPolicy Bypass -File ./install.ps1
```

**パスは `./` (スラッシュ) で書いてください。** `.\` (バックスラッシュ) だと Git Bash が
記号を食べてしまい「引数が存在しません」で失敗します。VS Code の既定ターミナルが
Git Bash の場合はこれを踏みます。

また、このスクリプトの表示は日本語なので、**PowerShell ターミナルで実行すると読めます**
(Git Bash だと文字化けします。動作自体は問題ありません)。

VS Code を再起動し、このフォルダを開いて `Ctrl+Alt+T`。

```bash
code C:\path\to\30_note
```

**会社PCに必要なのは VS Code 1.90 以降だけです。** 拡張機能は VS Code 内蔵の実行環境で動き、
外部ライブラリを一切使っていないので `npm install` もネット接続も要りません
(Node.js はテストを流したいときにだけ必要)。管理者権限も不要です。

### あとから直したものを反映する

個人PC側で直したら push し、会社PC側で pull するだけです。

```bash
git pull
```

`install.ps1` をジャンクションで入れていれば、pull した内容がそのまま反映されます
(VS Code を再読み込みするだけ)。`-Copy` で入れた場合は `install.ps1` を実行し直してください。

### 注意

- **会社の方針を先に確認してください。** github.com への接続が塞がれている職場があります。
  clone だけなら認証は要りませんが、push するときは会社PC側でログインが必要です
- リポジトリは public です。**業務に関わる内容をコミットしないこと。**
  記録は `.gitignore` で除外済みですが、`README.md` や `config.json` に
  社名・案件名を書かないよう注意してください
- `.taskchute/config.json` は追跡しています。節の時間帯を会社用に変えたい場合は、
  `git update-index --skip-worktree .taskchute/config.json` で追跡から外せます
- git が使えない場合は、**フォルダごとコピーしても動きます** (USB、OneDrive など)。
  ネット越しに受け取った場合は、展開後に一度
  `powershell -Command "Get-ChildItem -Recurse | Unblock-File"` を実行してください

`install.ps1` の補足:

| 状況 | やること |
| --- | --- |
| 会社PCでジャンクション (フォルダの別名) が作れない | 自動でコピーに切り替わる。明示するなら `-Copy` |
| VS Code の拡張機能フォルダが標準の場所にない | `-ExtensionsDir "D:\...\extensions"` を付ける |
| 取り除きたい | `-Uninstall` を付ける |

`-Copy` で入れた場合は、ソースを直すたびに `install.ps1` を実行し直してください。
ジャンクションで入っていれば、ソースを直して VS Code を再読み込みするだけで反映されます。

## TaskChute パネル

`Ctrl+Alt+T` で開きます。TaskChute2 のスタートアップガイドの考え方をそのまま持ってきています。

**マウスは使いません。** すべてキーボードで操作します。画面には常にモード表示が出ています。

- **NORMAL** — カーソルがセルの上を動き、1 文字キーがコマンドとして効く状態
- **EDIT** — カーソル位置のセルだけが入力欄になっている状態。`Esc` で NORMAL に戻る

### 画面の見方

**上段** — モード表示、基準日 (TaskChute の中で「今日」とみなす日)、現在時刻、
**今いる節**、**終了予定時刻**。

`Sec D Afternoon 13:00-17:00 32m left` のように、いまどの時間帯にいて、その枠があと何分残っているかが出ます。

終了予定時刻は「現在時刻 + 未完了タスクの見積の合計」です。カーナビの到着予想時刻と同じで、
遅れれば後ろにずれます。この数字を受け入れられないなら、タスクを削るか、翌日以降に送るか、
見積を短くするか、のどれかを今その場で決めます。

**2段目** — `Est` 見積 / `Done` 消化 / `Left` 残 / `Act` 実績 / `Carryover` 積み残し。カッコ内は件数です。

**3段目 (節別サマリー)** — 時間帯 (節) ごとの見積合計と、その時間帯の長さ。色に意味があります。

| 色 | 意味 |
| --- | --- |
| 青 | 上限時間に収まっている |
| 赤 | 上限を超えている、または終了した時間帯に未完了が残っている |
| 灰 | 終了した時間帯で、未完了が残っていない |
| 青地に白 | 今いる時間帯 |

**4段目** — 翌日以降10日間の見積合計。`,` `.` で基準日を動かせます。

**5段目** — いま押せるキーの案内。`?` で全部出ます。

### 実行中のタスク

開始を打刻して終了がまだのタスクは、**行全体が青くなり、左端に青い縦線が入ります**。
`Act` 欄にはその場で経過時間が出て、20 秒ごとに更新されます。打刻し忘れにも気づけます。

### 1日の流れ

1. 朝、`Ctrl+Alt+T` でパネルを開く。基準日が今日になっていることを確認する (ずれていたら `Shift+T`)
2. `n` でタスクを足し、`Tab` で右へ送りながら `Sec` (時間帯) と `Est` (分) を埋める
3. `2` キー (通常並べ替え) で並べ直し、節別サマリーの埋まり具合と終了予定時刻を見る
4. 上から順に、`s` で開始を打刻 → 終わったら `e` で終了を打刻 → `j` で次の行 → `t` で時刻を引き継ぐ
5. 割り込みが入ったら `n` でカーソル行の上に挿入し、見積は空のままにしておく (後から「予定外だった」と分かる)
6. 何をしていたか分からない時間ができたら `Shift+I` で `Idling` を挿入して埋める。10分だったのか42分だったのかは大きな違いです
7. 終わらなかったタスクは `d` で翌日以降へ送る

**NORMAL モード**

| `i` / `a` | このセルを編集 (`a` は末尾から) |

| `n` / `Shift+N` | カーソル行の上 / 下にタスクを追加 |

| `1` / `2` / `3` | 高速 / 通常 / 全力 並べ替え |

**EDIT モード**

| キー | 動作 |
| --- | --- |
| `Enter` | 確定して NORMAL に戻る |
| `Tab` / `Shift+Tab` | 確定して右 / 左のセルへ (編集を続ける) |
| `Esc` | 取消。候補が出ているときは、一度目で候補の選択だけ外す |
| `↑` `↓` (`Ctrl+p` `Ctrl+n`) | 候補を移動 |
| `Ctrl+Space` | `Date` `Due` セルでカレンダーを開く |

`Project` `Mode` `Task` `Sec` のセルは、編集を始めると候補の一覧が出ます。
打ち始めると前方一致で絞り込まれ、`Enter` で**選択中の候補**が入ります。
打った文字をそのまま入れたいときは、`Esc` で候補を閉じてから `Enter` を押します。

### 月日セル (`Date`) の書き方

`Date` のセルで `i` を押すと、短縮入力ができます (今日が 9月6日の場合)。

| 入力 | 結果 |
| --- | --- |
| `7` | 今月7日 (過ぎていれば翌月7日) |
| `9/7` `0907` | 9月7日 (過去になるなら翌年) |
| `+1` / `-1` | 翌日 / 前日 |
| `0` | 基準日 |
| `w` / `w2` | 1週間後 / 2週間後 |
| `m` / `y` | 1ヶ月後 / 1年後 |
| `火` / `tue` | 次の火曜 |
| `明日` `あさって` `today` | そのまま |
| `2026-09-07` | その日付 |

読めない文字を入れた場合は、日付は変わりません。

### カレンダー

`Date` / `Due` のセルで `Enter`、または `Ctrl+Space` でカレンダーが開きます。**すべてキーボードで動きます。**

| キー | 動作 |
| --- | --- |
| `←` `→` (`h` `l`) | 1日 |
| `↑` `↓` (`k` `j`) | 1週間 |
| `PageUp` / `PageDown` | 1ヶ月 |
| `Home` | 今日へ |
| `Enter` / `Esc` | 確定 / 取消 |

今日は枠線、基準日は薄い背景、そのタスクの現在の日付は黄色い枠で示されます。
**タスクが入っている日には緑の点**が付くので、送り先の混み具合を見ながら決められます。

### 期限 (`Due` 列)

**「いつまでに」を入れる欄です。`Date` の「いつやるか」とは別物**です。
急にもらったタスクを、期限を添えて記録しておくためのものです。

書き方は月日セルと同じ短縮入力（`9/12` `+3` `w` `火` など）。
**空欄のまま確定すると期限なしに戻ります。** `Enter` や `Ctrl+Space` でカレンダーも開きます。

期限が近づくと色が変わります。

| 色 | 意味 |
| --- | --- |
| 赤・太字 | 期限切れ |
| 赤 | 今日が期限 |
| 橙 | 2日以内 |
| 灰 | 完了済み（もう気にしなくてよい） |

**期限切れと今日が期限のタスクがあると、ヘッダに赤い枠で件数が出ます。** 見落としを防ぐためです。

`Ctrl+Alt+A` でも期限を付けられます。`!` に続けて書きます。

```
見積書を提出 /Work @Focus 60m !9/12
```

### タスクにメモ (.md) を紐づける

**任意です。**必要なタスクにだけ付ければ構いません。付いているタスクは `Note` 列に `●` が出ます。

行にカーソルを置いて **`Shift+O`**（`Note` 列で `Enter` でも同じ）。

- **まだ無いとき** — テンプレートの一覧が出ます。選ぶと `notes/2026-09-06-タスク名.md` が作られ、そのまま開きます。`Esc` で中止すればメモは作られません
- **既にあるとき** — そのまま開きます。二重に作られることはありません
- 同名のメモが既にあるときは `-2` `-3` と枝番が付きます

メモの先頭には、実行予定日・期限・Project・Mode・見積と、**その日のデイリーノートへのリンク**が自動で入ります。

#### 付け替え・紐づけを外す

`Note` 列で `i` を押すと、保存されているパスを直接編集できます。

- 別のファイルのパスを書けば、そのファイルに付け替わります
- **空欄にすれば紐づけが外れます。ファイル自体は消しません**

タスクを削除してもメモのファイルは残ります。消したいときは手で消してください。

#### テンプレートを増やす・変える

`80_tamplate/task/` に `.md` を置くだけで選択肢が増えます。設定は要りません。
最初から `メモ` `会議` `調査` の3つを置いてあるので、中身は自由に書き換えてください。
（1つしか置いていないときは、選択肢を出さずにそれが使われます）

テンプレートの中で使える差し込み文字です。

| 書き方 | 入るもの |
| --- | --- |
| `{{task}}` | タスク名 |
| `{{date}}` / `{{weekday}}` | 実行予定日 / 曜日 |
| `{{due}}` | 期限（`2026-09-12`） |
| `{{dueLine}}` | ` / 期限 2026-09-12 (土)`。期限が無ければ空 |
| `{{project}}` `{{mode}}` `{{section}}` | 各欄の値 |
| `{{estimate}}` | 見積（分） |
| `{{now}}` | 作成した日時 |
| `{{dailyLink}}` | その日のデイリーノートへのリンク |

置き場所を変えたいときは、VS Code の設定 `taskchute.taskNote.folder` と
`taskchute.taskNote.templateFolder` です。

### 絞り込み

タスクが増えて見通しが悪くなったときに使います。3つを重ねがけできます。

| キー | 効果 |
| --- | --- |
| `f` | 今日の未完了だけ表示。完了と翌日以降が消える |
| `Shift+P` | Project で絞る（一覧から選ぶ。件数も出ます） |
| `Shift+M` | Mode で絞る |
| `Shift+F` | すべて解除 |

絞り込み中はヘッダに黄色い枠で条件と「20件中 5件」という件数が出るので、
**一部しか見ていないことを見失いません。**

**大事な点：絞り込んでも、見積・消化・残・終了予定時刻・節別サマリーは一日ぶん全部で計算します。**
表示を絞ったせいで一日の総量が小さく見えると、判断を誤るためです。

絞り込み中に `n` でタスクを足すと、絞っている Project / Mode を引き継ぎます
（足した直後に消えてしまわないように）。

### 見積セル (`Est`) の書き方

| 入力 | 結果 |
| --- | --- |
| `90` | 90分 |
| `45m` `45分` | 45分 |
| `1.5h` `1.5時間` | 90分 |
| `1:30` `1h30` | 90分 |

### 日付変更ダイアログ (`d`)

TaskChute と同じ作法で、**空欄のまま Enter は翌日**です。
符号なしの数字も相対日数として扱います (`2` = 2日後)。それ以外は月日セルと同じ書き方が使えます。

### 3種類の並べ替えの違い

| 種類 | 中身 |
| --- | --- |
| 高速 (`1`) | 並べ替えるだけ。区切り (`Divider`) タスクの先送りをしない |
| 通常 (`2`) | 区切り (`Divider`) タスクを先送りする。ふだんはこれ |
| 全力 (`3`) | 通常に加えて、翌日以降も節内ソート順で整える |

並べ替えの基準は **`Sec` → `★` → `#`**。翌日以降のタスクは `#` の代わりに **`Order` (節内ソート順)** を見ます。

### 区切りタスク (`Divider`)

Project を `Divider` にして、`Order` (節内ソート順) に `1730` のように4桁の時刻を入れておくと、
その時刻を過ぎた状態で通常/全力の並べ替えをしたときに、自動で翌日へ送られます。
「17:30 には退勤する」のような区切りを、毎日引き継ぐための仕組みです。

### 繰り返しタスク

`r` で設定します。毎日 / N日ごと / 平日 / 曜日指定 / 毎月 / 毎年 に対応。
**終了時刻を入れた瞬間に、次回分が自動で作られます。**

`b` で時間帯 (節) を固定しておくと、いつもと違う時間帯に終わらせても、次回はいつもの時間帯に入ります。

### 節内ソート順 (`Order` 列)

翌日以降のタスクの並び順を決める4桁の数字です。`0800`, `0815`, `0830` のように見積に沿って
振っておくと、毎朝のルーチンが「いつもの順番」で再現されます。間を空けておくと、後から `0813`
のようなタスクを差し込むときに、後続の番号を振り直さずに済みます。

## 設定を変える

`.taskchute/config.json` (パネルで `Shift+C` を押すと開きます) で、以下を変えられます。

- `sections` — 時間帯 (節) の区切り。A〜L まで最大12個
- `projects` — Project 欄の候補
- `modes` — Mode 欄の候補と色。Project とは別の切り口の分類
- `dividerProject` — 区切りとして扱う Project 名 (既定 `Divider`)
- `view` — 画面に読み込む前後の日数
- `columns` — **列ごとの表示 / 非表示と幅**

編集したらパネルで `F5` (再読込) を押してください。

### 列を増やしたい・減らしたい

`columns` の `visible` を切り替えます。既定では `#` `Order` `Hint` `Comment` を隠しています
(既定の13列で 832px)。使わない列は `visible` を `false` にすると縮みます。

```json
"hint": { "label": "Hint", "visible": true, "width": 180 }
```

`width` は px です。`Task` の列だけは、余った幅を吸って自動で広がります。
一時的に全部見たいときは、設定を変えずに `\` キーで切り替えられます。

## バックアップ

すべてただのテキストファイルです。`30_note` フォルダをコピーすれば、それがそのまま
バックアップであり、移行用のパッケージでもあります。

## Outlook 連携について

会社PC側に予定表があるため、この個人PCからは直接つなげません。**取り込み口だけ**用意してあります。

- コマンドパレット → `TaskChute: ICS ファイルから予定を取り込む`
- Outlook で予定表を `.ics` (予定表の標準ファイル形式) に書き出し、そのファイルを選ぶと、
  予定が Project `Event` のタスクとして取り込まれます (見積 = 予定の長さ)
- 同じ予定を再度取り込んでも二重になりません (予定の ID で照合します)
- 開始/終了の実績時刻は入れません。入れると完了扱いになってしまうためです

**会社PCにこの環境を移したら**、そこでは Outlook を COM (アプリ間連携の仕組み) 経由で
直接読めるようになります。認証もネット接続も要らず、一番確実な方法です。移行が済んだら
その実装を足すのがおすすめです。

(`-Copy` で入れた場合は先に `install.ps1` を実行し直す)。
